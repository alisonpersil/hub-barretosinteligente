📈 Guia de Implantação no Power BI

Como transformar este modelo e a base de dados em um relatório Power BI oficial

Já geramos na pasta do projeto o arquivo consolidado base_consolidada_powerbi.xlsx. Para criar no Power BI Desktop, basta importar as abas Historico_Mensal, Backlog_Pendentes e Desempenho_Equipes_2026 e criar as seguintes Medidas DAX:

1. Percentual de SLA Cumprido no Prazo (% SLA)

% SLA no Prazo = 
DIVIDE(
    CALCULATE(COUNTROWS(fAtendidos), fAtendidos[Atraso] = "Não"),
    CALCULATE(COUNTROWS(fAtendidos), fAtendidos[Atraso] IN { "Não", "Sim" }),
    0
)

2. Backlog Total de Pontos Físicos

Backlog Pontos = SUM(fPendentes[pontos])

3. Média Diária de Atendimentos

Media Diaria Atendimentos = 
AVERAGEX(
    VALUES(dCalendario[Data]),
    CALCULATE(COUNTROWS(fAtendidos))
)

4. Dias Preditivos para Zerar Backlog (What-If Parameter)

Dias Para Zerar Backlog = 
VAR BacklogAtual = [Backlog Pontos]
VAR CapacidadeDiaria = SELECTEDVALUE('Parametro Capacidade'[Valor], 15)
RETURN
DIVIDE(BacklogAtual, CapacidadeDiaria, 0)
